## 1. 快速开始

### 环境要求

| 依赖 | 版本要求 | 必需 |
|------|---------|------|
| macOS | 必须 | 是 |
| WeChat | 4.x | 是 |
| Node.js | 20+ (推荐 22.x) | 是 |
| pnpm | 10+ | 是 |
| wx-cli | 0.3+ | 是 |
| Codex CLI | 最新版 | 否（AI 摘要功能需要） |

### 安装步骤

```bash
# 1. 克隆项目
git clone https://github.com/zjp1997720/wechat-radar.git
cd wechat-radar

# 2. 安装依赖
pnpm install
pnpm rebuild better-sqlite3

# 3. 安装 wx-cli
npm install -g @jackwener/wx-cli

# 4. 初始化微信数据读取（需要微信保持运行）
codesign --force --deep --sign - /Applications/WeChat.app
sudo wx init

# 5. 配置环境变量
cp .env.example .env.local
# 编辑 .env.local，填入你的微信昵称

# 6. 启动
pnpm dev
```

启动后访问 **http://localhost:3000**，首次会自动跳转到配置页面。

## 2. 初始配置

**页面路径**: `/setup`

首次启动应用会自动跳转到此页面，分为 4 个配置区域：

### 2.1 环境检查

系统自动检测运行环境：

- **wx-cli 安装状态** — 显示 ✓ 已安装 或 ✗ 未检测到
- **wx-daemon 运行状态** — 显示 ✓ 运行中 (PID) 或 ✗ 未运行
- **数据目录** — 显示本地数据存储路径（默认 `~/.wechat-radar`）

### 2.2 微信昵称

输入你在微信中的昵称，**支持多个名称，用英文逗号分隔**。

```
示例: 崔朋, cuip, Peng Cui
```

用途：
- 识别群里 @你 的消息
- 在统计中标记你自己的发言

### 2.3 数据模式

- **使用示例数据体验** — 勾选后使用演示数据，无需 wx-cli
- **首次同步天数** — 下拉选择：
  - 最近 1 天
  - 最近 7 天（推荐）
  - 最近 30 天
  - 最近 365 天（完整同步，耗时 8-15 分钟）

### 2.4 隐私确认

必须勾选以下两项才能保存配置：

- "我理解聊天数据会存储在本地 SQLite 中，不会自动上传"
- "我会自行确认数据读取和处理符合相关规则"

点击 **"完成配置"** 保存后自动跳转到主看板。

## 3. 界面总览

### 侧边栏导航

应用左侧固定侧边栏，包含以下导航项：

**主导航 (MAIN)**

| 菜单项 | 图标 | 路径 | 说明 |

| 菜单项 | 图标 | 路径 | 说明 |
|--------|------|------|------|
| 所有群 | Inbox | `/groups` | 全部群聊列表 |
| 收藏 | Star | `/groups?filter=favorites` | 已星标的群 |

### 主题切换

侧边栏顶部有 🌙/☀️ 图标按钮，点击切换深色/浅色主题。主题偏好保存在 localStorage。

## 4. 驾驶舱看板

**页面路径**: `/`

这是应用的主页面，汇集所有关键情报。

### 4.1 顶部控制栏

从左到右依次为：

| 控件 | 说明 |
|------|------|
| **全局搜索框** | 输入关键词搜索群、话题、人、消息、链接（至少 2 字符） |
| **日期选择器** | 选择具体日期查看数据 |
| **时间范围** | 分段按钮：日 / 周 / 月 / 季 / 年 |
| **全量同步** | 一次性同步过去 365 天所有消息（耗时 8-15 分钟） |
| **重扫** | 刷新当前时间范围内的消息数据 |

### 4.2 统计卡片

页面顶部 4 张统计卡片：

| 卡片 | 含义 | 可点击 |
|------|------|--------|
| **活跃群** | 时间范围内有消息的群数量 | 否 |
| **总消息** | 消息总条数 + 平均每群条数 | 否 |
| **@ 我的** | 提及你的消息数量 | **是** → 跳转到 /mentions |
| **静默群** | 时间范围内无活动的群数量 | 否 |

### 4.3 情报简报

情报简报面板是看板的核心区域，分为多个子模块：

#### 今日先看这些

4 列网格展示当日最值得关注的内容：

- **高信号消息** — 经算法筛选的重要消息（基于长度、关键词、URL 权重）
- **精选文章** — 当日群里分享的优质文章
- **工具资源** — 当日群里分享的工具/项目链接
- **异动信号** — 群活跃度突增/突降等异常

右上角 **"复制摘要"** 按钮可将整个简报复制为 Markdown 格式。

#### 关键话题与消息

按信号强度排序的消息列表，每条显示：
- 消息标题
- 来源群名 + 发送人 + 时间
- 为什么是高信号的理由

点击任意条目跳转到对应群详情。

#### 链接情报

分两列展示：
- **文章/内容** — 新闻、公众号文章、技术博客
- **工具/资源** — 开源项目、产品、SaaS 工具

每条链接显示标题、域名、引用次数，点击直接打开。

#### 需要盯一下

- **系统异动** — 活跃度异常的群聊，标注严重性（高/中/低）
- **高信号人物** — 基于发言质量和跨群影响力排序的活跃用户

### 4.4 趋势图表

ECharts 柱状图展示选定时间范围内的**每日消息量**：
- 峰值标注
- 平均线
- 点击某日柱子可跳转查看该日数据

### 4.5 智能活跃群列表

按消息活跃度排序的群列表，显示：
- 排名、群名、Top 发言人、消息数
- 前 10 名群有 **"日报"** 按钮，点击进入群日报页面

## 5. 群聊管理

**页面路径**: `/groups`

### 5.1 群列表

默认显示所有群聊，每条显示：
- 群名 + 未读消息数（红色徽章）
- 最后一条消息摘要
- 更新时间
- ⭐ 收藏按钮（点击切换收藏状态）

### 5.2 筛选功能

通过侧边栏或 URL 参数切换筛选模式：

| 筛选 | 路径 | 说明 |
|------|------|------|
| 所有群 | `/groups` | 显示全部群聊 |
| 收藏 | `/groups?filter=favorites` | 仅显示已星标的群 |
| 未分组 | `/groups?filter=unsorted` | 仅显示未归入任何分组的群 |
| 按分组 | `/groups?filter=group&group_id=1` | 显示指定分组下的群 |

### 5.3 搜索

页面右上角搜索框，支持按**群名**或**最近消息内容**实时过滤。

### 5.4 收藏与分组

- **收藏**: 点击群列表中的 ⭐ 图标即可收藏/取消收藏
- **分组**: 通过 [AI 智能分类](#12-ai-智能分类) 页面或手动管理

## 6. 群详情与消息

**页面路径**: `/groups/[chatroom_id]`

点击群列表中的任意群进入详情页。

### 6.1 历史趋势

顶部柱状图展示该群**历史每日消息量**：
- 当前选中日期的柱子高亮为绿色
- 点击其他日期的柱子可快速切换

### 6.2 当日分布

24 小时消息分布柱状图，直观展示群活跃时段。

### 6.3 统计面板

两栏布局：
- **Top 发言人** — 当日前 12 名发言人及消息条数
- **消息类型** — 文本/图片/链接/视频等消息类型占比

### 6.4 完整消息列表

当日所有消息的时间线，每条显示：

| 列 | 内容 |
|------|------|
| 发送人 | 消息发送者昵称 |
| 消息内容 | 完整消息文本（含链接渲染） |
| 消息类型 | text / image / link / video 等 |
| 时间 | HH:MM:SS 格式 |

**复制功能**: 右上角 **"复制"** 按钮将当日所有消息复制为 Markdown 格式：

```markdown
# 群名 2024-01-22

[13:45] 张三: 大家看看这个工具
[13:46] 李四: 不错，收藏了
[13:50] 王五: 推荐这个 https://example.com
```

复制后可直接粘贴给 AI（如 Claude）做进一步分析。

## 7. 群日报

**页面路径**: `/reports/groups/[chatroom_id]?date=YYYY-MM-DD`

从驾驶舱活跃群列表的 **"日报"** 按钮进入。

### 7.1 日报结构

日报自动从当日消息中提炼以下内容：

#### 核心主题

每个主题包含三部分：
- **聊了什么** — 对话内容概括
- **为什么重要** — 重要性说明
- **引用/证据** — 代表性原始消息引用

主题通过规则引擎识别，覆盖的关键词领域包括：
- AI/大模型（Claude、GPT、Codex 等）
- 编程工具与 MCP
- AIGC 与内容创作
- 营销与商业
- 开源与产品
- 活动与报名

#### 工具/文章/链接

从消息中解析的所有链接，去重后展示标题和 URL。

#### 可跟进项

包含 "求推荐"、"有没有"、"怎么" 等关键词的提问消息，提示你可能需要回复或关注。

#### Top 发言人

当日前 8 名活跃发言人及消息条数。

### 7.2 复制日报

右上角 **"复制日报"** 按钮将完整日报复制为 Markdown 格式，方便：
- 发到其他群/频道
- 粘贴给 AI 做深度分析
- 归档到笔记工具

## 8. 话题雷达

**页面路径**: `/topics`

> 需要配置 Codex CLI 才能使用此功能。

话题雷达是 wechat-radar 的标志功能——**跨群话题聚合**。当多个群在讨论同一个话题时，系统会自动识别并汇总。

### 8.1 自动构建

首次打开某日的话题雷达时，系统自动触发构建流程：

1. 加载当日所有群消息
2. 清洗消息（去除图片占位、系统消息、过短内容等）
3. 分块发送给 Codex CLI 进行 NLP 聚合
4. 保存话题到数据库

构建进度实时显示在页面顶部。

### 8.2 话题浏览

左右分栏布局：

**左侧 — 话题列表**

每个话题卡片显示：
- 话题标题
- 摘要（2 行以内）
- 消息数量
- 涉及群数量

**右侧 — 话题详情**

点击某话题后显示：
- 完整标题和摘要
- 元数据（消息数、跨群数、日期）
- 所有源消息列表，每条标注来源群名、发送人和时间

### 8.3 手动重建

如果对自动构建结果不满意，点击右上角 **"构建话题"** 按钮重新构建当日话题。

## 9. 链接情报

**页面路径**: `/links`

### 9.1 三列布局

| 列 | 内容 | 说明 |

- 标题（AI 生成或从消息提取）

## 11. 实时信号流

**页面路径**: `/signals`

类似消息监控台，实时显示最新到达的微信消息。

### 11.1 工作原理

- 每 **5 秒** 轮询一次 wx-cli 获取新消息
- 新消息插入列表顶部
- 最多保留最近 **200 条**消息

### 11.2 控制

- **暂停** — 停止拉取新消息，已有消息保留
- **继续** — 恢复实时拉取

### 11.3 消息显示

每条消息显示：
- 群名 + 发送人
- 消息内容（单行截断）
- 消息类型
- 时间戳

## 12. AI 智能分类

**页面路径**: `/classify`

帮助你将未分组的群自动归类到合适的分组。

### 12.1 分类建议

系统基于启发式规则（群名关键词 + 最近消息内容）自动推荐分组：

| 规则示例 | 建议分组 |
|---------|---------|
| 群名含 "编程/CLI/MCP/Vibe" | Vibe Coding · 编程 |
| 群名含 "AIGC/创作/设计" | AIGC · 内容创作 |
| 群名含 "商业/营销/增长" | AI 商业 · 营销 |
| 群名含 "学术/论文/研究" | AI 学术 |
| 群名含 "付费/会员/VIP" | 付费社区 |

### 12.2 操作流程

1. 进入页面后自动显示所有未分组的群及其建议
2. 查看每条建议的理由
3. 可通过下拉框修改建议的目标分组，或选择 "— 跳过 —"
4. 确认后点击 **"应用"** 按钮批量生效
5. 应用后列表自动刷新

## 13. 搜索功能

### 13.1 全局搜索

位于驾驶舱顶部控制栏，支持搜索：
- 群名
- 话题标题
- 发言人

### 13.2 页面内搜索

## 14. 数据同步

### 14.1 重扫（局部同步）

点击顶部栏 **"重扫"** 按钮：
- 同步当前时间范围内（日/周/月/季/年）的消息
- 耗时 1-3 分钟
- 实时显示进度：`同步中 30/45 (67%) · 已存 3200 条 · 群X`

### 14.2 全量同步

点击顶部栏 **"全量同步"** 按钮：
- 一次性同步过去 365 天的所有消息
- 耗时 8-15 分钟
- 同步完成后自动构建话题（可配置天数范围）

### 14.3 同步进度

同步过程通过 Server-Sent Events 流式更新：

```
同步启动 → 加载群列表 → 逐群同步消息 → 入库 → 构建话题 → 完成
```

同步期间可以继续浏览已有数据，不影响使用。

## 15. 配置参考

### 15.1 环境变量 (.env.local)

| 变量 | 默认值 | 说明 |
|------|-------|------|
| `WECHAT_RADAR_DATA_DIR` | `~/.wechat-radar` | 数据存储目录 |
| `WECHAT_RADAR_MY_NAMES` | 空 | 逗号分隔的微信昵称 |
| `WECHAT_RADAR_DEMO` | `0` | 设为 `1` 启用演示模式 |
| `WECHAT_RADAR_CODEX_MODEL` | 空 | Codex CLI 使用的模型名（如 `gpt-5.5`） |
| `WECHAT_RADAR_TOPIC_CHUNK_SIZE` | `250` | 话题聚合每块消息字符数 |
| `WECHAT_RADAR_CODEX_TIMEOUT_MS` | `300000` | 话题聚合超时（毫秒） |
| `WECHAT_RADAR_LINK_CODEX_TIMEOUT_MS` | `180000` | 链接标题生成超时（毫秒） |
| `WECHAT_RADAR_AUTO_TOPIC_DAYS` | `31` | 全量同步时自动构建话题的天数 |

### 15.2 配置文件 (~/.wechat-radar/config.json)

通过 `/setup` 页面管理，也可手动编辑：

```json
{
  "myNicknames": ["崔朋", "cuip"],
  "demoMode": false,
  "privacyConfirmed": true,
  "setupCompleted": true,
  "defaultSyncDays": 7,
  "rescanConcurrency": 5
}
```

### 15.3 数据目录结构

```
~/.wechat-radar/
├── radar.db          # SQLite 主数据库（所有消息、话题、统计）
├── config.json       # 用户配置
└── backups/          # 数据库备份
```

### 15.4 数据库备份

```bash
pnpm run db:backup
```

在 `~/.wechat-radar/backups/` 生成带时间戳的备份文件。

## 16. 常见问题

### Q: "wx-daemon 未运行" 怎么办？

```bash
# 检查状态
wx daemon status

# 启动守护进程
wx daemon start
```

### Q: 话题雷达显示 "暂无话题"？

1. 确认已配置 `WECHAT_RADAR_CODEX_MODEL`（如 `gpt-5.5`）
2. 确认 Codex CLI 已安装且可用：`codex --version`
3. 点击 "构建话题" 手动触发构建
4. 查看浏览器控制台是否有错误信息

### Q: better-sqlite3 安装失败？

Node.js 23.x 缺少预编译二进制。解决方案：

```bash
# 使用 Node 22 安装
PATH="/opt/homebrew/opt/node@22/bin:$PATH" pnpm install
```

### Q: 页面报错 "list is not iterable"？

wx-cli 版本更新后返回格式可能变化。检查 `lib/wx.ts` 中的 `wxSessions` 函数，确保兼容 `{sessions: [...]}` 包装格式。

### Q: 如何只关注部分群？

目前没有白名单/黑名单功能，所有群数据都会同步。但可以通过以下方式聚焦：
- **收藏** — 星标重要群，用 "收藏" 筛选查看
- **分组** — 创建自定义分组，归类管理
- **搜索** — 用关键词快速定位

### Q: 数据安全吗？

所有数据存储在你的本机 `~/.wechat-radar/` 目录，使用 SQLite 数据库，**不会自动上传到任何云端服务**。Codex CLI 调用时会将消息内容发送给 OpenAI API。

### Q: 如何更新到最新版本？

```bash
cd /path/to/wechat-radar
git pull
pnpm install
```
